# 出生在这里 · 从前与此刻

一段从2003年出生到2040年的虚构普通人生。16个场景，三条起步路线，三种未来社会情景，六种按累积选择计算的结局。

游玩地址：https://2813750541a-ops.github.io/then-and-now-particle-game/after-birth/

## 怎么玩

戴上耳机，点击「从出生开始」。物件旁会出现交互提示：按住孩子、背起书包、投递简历、维修故障、送包裹、安抚孩子、把照护包送到父母身边。拖动物件对应提示按钮。键盘 Tab 聚焦后，Enter 可以完成同一动作。

不设置失败倒计时。继续按钮在一段动作和反馈完成后出现。暂停菜单可以重新开始、查看音乐和时代资料。手机可玩；横屏更适合看运镜与纵深。

三个小游戏融入剧情：开学前点击收集课本、铅笔和饭盒；童年把六块粒子合影拼回一家三口；早早工作路线规划三单配送并逐单拖动送达。拼图可以点击两块交换，也可以选择“一起拼好”；配送不设超时惩罚，规划顺路会少耗一点精力。

每次进入新场景自动保存起点。刷新后可继续该场景，不重复累计同一次选择。结尾可保留成长经历，返回2030年试走另一种未来。

## 三条路会交叉

读本科、学手艺、早早工作决定最初遇见的任务；学习、休息、住房承诺、伴侣分工、父母沟通、照护安排持续影响后面的余地。学历、工种和生育选择没有固定对应的优劣结局。

## 关于“未来预测”

2027—2040全部是标注在画面上的情景推演，不是确定预测。新技术带来部分新入口、机会与订单分配更不均、当地照护和技能支持逐步扩大，是三个可比较的假设，没有概率排名，也可能在现实中同时出现。

人物和个人经历都是创作。虚构资源单位不等于工资、真实开支、就业概率、疾病风险或个人诊断。结局只反映规则如何累计选择，不能用来判断真实玩家的人生。

## 源码与素材

`game.js` 包含点云引擎、场景动作与状态规则；`index.html` 提供全屏游戏界面。只渲染 `THREE.Points`，没有 Mesh、实体模型、人物建模或模型加载器。音乐、声音与 Three.js 从父目录 `assets/` 读取，字体为本版文字重新制作的 Noto SC 子集。源码应连同父目录一起下载后使用。

配乐与素材署名见父目录《音乐与素材署名.md》，历史与未来依据见本目录《时代与未来情景.md》。
